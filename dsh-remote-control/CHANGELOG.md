# 更新日志

## 0.7.0 — 输入框上方目标指示器 + 面板改版

- 新增输入框上方状态条（`conversation.input.dock`）：显示「本机」或「远程 · 电脑名 · 工作区」，点击展开菜单就地切换；该目标只是工具默认值，不改变命令权限或隔离环境。
- 登记表新增 `activeMachineId` 记录当前目标：工具省略 `machine` 时使用当前目标；显式 `machine` 仍优先并会更新当前目标；切回本机后省略 `machine` 的调用会明确报错而不是猜测。
- 移除机器或删除目标机器时自动清理失效的当前目标。
- 新增面板接口 `GET /state`、`POST /activate`（与其它设置接口一样仅限本机回环）。
- 设置页面板改版：卡片分区、自适应网格表单、当前目标高亮与「设为当前 / 切回本机」、空状态、在线/繁忙/版本/默认目录分层展示。
- 既有能力与安全边界不变；`machine` 变为可选不影响显式调用的行为。

## 0.6.0 — 机器目录与默认运行配置

- 新增 `remote_machine_configure(machine, name?, enabled?, auto_connect?, default_cwd?, default_env?)`：重命名、启停、启动探活与默认运行配置。默认目录在线验证，调用时的环境变量覆盖默认值。
- 同步/后台执行按显式 `cwd`、机器 `defaultCwd`、远程工作区选择目录；无目录则报错。切换工作区验证目录并清除旧默认目录。
- 机器目录增加 15 秒探测缓存、`refresh=true` 强制刷新、繁忙/未知状态、最后在线、主机名及 agent 版本。`probe=false` 不联网；自动连接默认关闭，开启仅在启动时探活。
- 移除在线/繁忙机器默认拒绝，需显式 `force=true`；面板直接显示拒绝原因，不自动强制移除。
- 面板增加自动连接复选框、繁忙徽标、最近状态和默认执行目录；默认环境变量只展示名称。配置接口限定本机回环来源，拒绝公网 Host、代理转发与跨站变更。
- agent **1.5.0**：健康检查上报忙碌任务和保持唤醒状态；可选 `--keep-awake` 请求阻止休眠，不修改系统电源设置，效果受平台与权限影响。
- 文件 API 改善符号链接/上传路径检查与资源使用约束；`--root` 仍仅约束文件 API，不是 shell 沙箱。
- 公网隧道要求 TLS（回环 HTTP 测试除外）；拒绝重定向，请求期限覆盖响应正文读取；不自动重放可能已经执行的写操作。
- 修正文档中的凭据和边界说明：`token_sha256` 值本身仍是 bearer secret；Windows `0600` 不等于私有文件权限；工作区和默认目录不提供隔离；隧道限额随服务商变化。
- 未新增云端执行服务或 DSH 会话执行主机选择器；借鉴的是远程机器目录与配置管理方式。

## 0.5.0 — 公网隧道模式（跨 NAT 控制）

### 新增

- **可选公网隧道**：登记表新增 `tunnelUrl` 字段。设置后请求优先走隧道（支持 `https://`），
  在可以确认请求尚未送达的连接错误下尝试直连/反向路径；不对可能已执行的操作重放请求。
- **`remote_tunnel` 工具**：`set`（设置并立即探活、读取目标机版本）、`show`（查看隧道与连通性）、
  `clear`（清除隧道，回退直连）。
- **`remote_machine_add(tunnel_url=…)`**：登记时直接挂隧道地址。目标机只需
  `cloudflared tunnel --url http://127.0.0.1:5188`，无需放行任何入站端口。
- **`remote_diagnose(host=…)` 支持 URL**：host 传隧道地址时改为纯 HTTP 层诊断
  （区分 DNS/证书失败、502/503、401）。
- **设置页面板**：新增「公网隧道地址」输入框，列表显示 `隧道` 徽标与当前地址。

### 行为约束（仅隧道路径）

- 隧道模式默认将同步执行超时保守限制为 **90 秒**，较长任务使用 `remote_exec_bg`。
- 隧道上传默认单文件阈值 **95 MiB**，超限报错；下载仍受服务商及链路限制。
- 上述数值是插件默认值，服务商与套餐的实际限额可能不同，不代表统一的 Cloudflare 硬限制。
- quick tunnel 地址每次重启可能变化，用 `remote_tunnel(action=set)` 更新即可，不必重装 agent。

## 0.4.0 — 后台长任务 + agent 版本对账

### 新增

- **agent v1.4.0 后台作业 API**：`/job/start`、`/job/list`、`/job/output`、`/job/kill`。
  - 命令在目标机独立运行，HTTP 请求立即返回，不受单次请求超时限制。
  - stdout/stderr 分别缓冲到 `--max-output`（默认 1MB），超出只标记截断，不继续占内存。
  - 已完成任务保留 1 小时、最多 64 个；agent 收到 SIGINT/SIGTERM 时结束所有未完成任务。
- **新工具 `remote_exec_bg`**：远程后台执行长命令（构建、测试、长脚本），立即返回 `job-xxxx`。
- **新工具 `remote_job`**：`list` / `status` / `output` / `kill`，`output` 默认回显最后 20000 字符。
- **`remote_machine_list` agent 版本对账**：目标机 agent 低于本包内置版本时提示用
  `remote_deploy_command` 重新部署升级。

### 兼容性

- 后台任务需要目标机 agent ≥ 1.4.0。旧 agent 上调用 `remote_exec_bg` 会得到 404，
  按提示用 `remote_deploy_command`（或再次 `remote_connect`）重新部署即可。
- 其余工具与 0.3.0 行为一致，登记表格式未变（`version: 1`）。
